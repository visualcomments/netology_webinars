# Вебинар 1: Практическое применение ML для задач в области финтеха

## Обзор темы

Машинное обучение в финтехе — это применение алгоритмов ML для решения задач в финансовой сфере: кредитный скоринг, обнаружение мошенничества, алгоритмическая торговля, оценка рисков, персонализация продуктов.

## Ключевые направления ML в финтехе

### 1. Кредитный скоринг
**Задача:** Предсказать вероятность дефолта заёмщика.

**Данные:**
- Возраст, доход, кредитная история
- Количество кредитов, просрочки
- Сумма запрашиваемого кредита

**Метрики:** ROC-AUC, Precision-Recall AUC, KS-статистика

### 2. Обнаружение мошенничества (Fraud Detection)
**Задача:** Выявить подозрительные транзакции в реальном времени.

**Особенности:**
- Сильный дисбаланс классов (0.1-1% мошеннических операций)
- Необходимость работы в реальном времени
- Высокая цена ошибки (false negative = потеря денег)

**Методы:**
- Isolation Forest, One-Class SVM
- Gradient Boosting с балансировкой
- Ансамбли моделей

### 3. Алгоритмическая торговля
**Задача:** Предсказать движение цены актива.

**Данные:**
- Исторические цены и объёмы
- Новостной фон (NLP)
- Макроэкономические показатели

**Методы:**
- Временные ряды (ARIMA, Prophet)
- LSTM, Transformer
- Reinforcement Learning для управления портфелем

### 4. Персонализация финансовых продуктов
**Задача:** Рекомендовать продукты клиенту.

**Методы:**
- Collaborative filtering
- Content-based filtering
- Hybrid approaches

## Практический пример: Кредитный скоринг

```python
import pandas as pd
import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.ensemble import GradientBoostingClassifier
from sklearn.metrics import roc_auc_score, classification_report
import matplotlib.pyplot as plt

# === Генерация синтетических данных ===
np.random.seed(42)
n_samples = 10000

data = {
    'age': np.random.randint(18, 70, n_samples),
    'income': np.random.lognormal(mean=10, sigma=0.8, size=n_samples),
    'credit_history_length': np.random.randint(0, 20, n_samples),
    'num_credit_cards': np.random.randint(0, 10, n_samples),
    'debt_to_income_ratio': np.random.uniform(0, 0.8, n_samples),
    'num_delinquencies': np.random.poisson(0.5, n_samples),
    'employment_years': np.random.randint(0, 30, n_samples),
    'loan_amount': np.random.lognormal(mean=9, sigma=1, size=n_samples),
}

df = pd.DataFrame(data)

# Целевая переменная: дефолт (1) или нет (0)
# Вероятность дефолта зависит от факторов
default_prob = (
    0.3 - 0.002 * df['income'] / 10000
    + 0.01 * df['debt_to_income_ratio']
    + 0.05 * df['num_delinquencies']
    - 0.005 * df['credit_history_length']
    + np.random.normal(0, 0.1, n_samples)
)
df['default'] = (default_prob > 0.3).astype(int)

print(f"Доля дефолтов: {df['default'].mean():.2%}")

# === Предобработка ===
X = df.drop('default', axis=1)
y = df['default']

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42, stratify=y
)

scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled = scaler.transform(X_test)

# === Обучение модели ===
model = GradientBoostingClassifier(
    n_estimators=200,
    max_depth=5,
    learning_rate=0.1,
    min_samples_split=50,
    random_state=42
)
model.fit(X_train_scaled, y_train)

# === Оценка ===
y_pred_proba = model.predict_proba(X_test_scaled)[:, 1]
roc_auc = roc_auc_score(y_test, y_pred_proba)
print(f"ROC-AUC: {roc_auc:.4f}")

# === Важность признаков ===
feature_importance = pd.DataFrame({
    'feature': X.columns,
    'importance': model.feature_importances_
}).sort_values('importance', ascending=False)

print("\nВажность признаков:")
print(feature_importance)

# === Определение порога отсечения ===
from sklearn.metrics import precision_recall_curve

precision, recall, thresholds = precision_recall_curve(y_test, y_pred_proba)

# Находим порог с F1 > 0.7 и максимальной точностью
f1_scores = 2 * (precision * recall) / (precision + recall + 1e-8)
best_threshold = thresholds[np.argmax(f1_scores)]
print(f"\nОптимальный порог: {best_threshold:.3f}")

# === Применение модели на новых данных ===
new_client = pd.DataFrame([{
    'age': 35,
    'income': 80000,
    'credit_history_length': 10,
    'num_credit_cards': 3,
    'debt_to_income_ratio': 0.3,
    'num_delinquencies': 0,
    'employment_years': 8,
    'loan_amount': 500000
}])

new_client_scaled = scaler.transform(new_client)
default_probability = model.predict_proba(new_client_scaled)[0, 1]
print(f"\nВероятность дефолта нового клиента: {default_probability:.2%}")
print(f"Решение: {'Одобрить' if default_probability < 0.3 else 'Отказать'}")
```

## Практические советы

1. **Работа с дисбалансом:** Используйте SMOTE, class_weight, или undersampling majority class
2. **Валидация:** Временное разделение (train на старых данных, test на новых)
3. **Интерпретируемость:** SHAP values для объяснения решений регулятору
4. **Мониторинг:** Дрейф данных и концепта требует регулярного переобучения
